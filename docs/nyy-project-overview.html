想传文件？拿呀²。

拿呀²（nyy.app）是一个从零自研的轻量文件分享与收文件工具：浏览器将文件本体直接上传到豆包 TOS / 火山 CDN，VPS 只保存元信息、分享关系、权限与审计数据——不中转流量，也几乎不占磁盘。覆盖上传、分享、预览、收件、工作台、管理后台与增长 SEO 的完整全栈闭环。

项目定位

轻量文件中转站，
把「传文件」做成一等公民。

面向自由职业者、设计师、二手交易、跨平台用户与播客主，解决「临时、大文件、免安装」的传输需求：发送方拖拽即传，接收方打开短链接即可预览、打包下载或直接收件。

是什么

类奶牛快传的轻量文件中转站：6 位短码直达分享落地页，支持提取码、有效期与下载次数限制、在线预览、打包下载与反向收件链接。

核心理念

文件本体直传对象存储（浏览器 ↔ 豆包 TOS / 火山 CDN），VPS 只存元信息与权限关系。实测单 PUT 上限 1 GiB 内稳定直传，流量与存储成本都被推到 CDN 侧。

目标用户

临时大文件分享场景：作业交付、摄影成片、设计稿、合同回传、视频素材跨端互传；注册用户可管理分享与收件，管理员可运营与风控。

CORE PRINCIPLE — ARCHITECTURE

浏览器 直传 → 豆包 TOS / 火山 CDN，下载凭据按时签发；VPS 不中转文件流量，只承担元信息、配额、权限、审计与风控。上传 1 GiB 无需经过服务器，打包下载在浏览器端流式完成。

核心功能

从发文件到收文件，全流程闭环。

六个模块覆盖一条完整链路：传输 → 分享 → 下载/预览 → 收件 → 工作台 → 管理与风控。

上传 · 浏览器直传

  • 拖拽 / 粘贴 / 文件夹 / 手机拍照选图
  • 3 并发队列，每文件独立进度、速度与剩余时间
  • 失败指数退避重试；IndexedDB 断点续传
  • 分片上传（64 MB 片，实测参数固化）
  • 客户端流式 CRC32 + SHA256 校验

分享 · 短码直达

  • 6 位 base62 短码（≈568 亿组合）根路径直达
  • 有效期 1h / 1d / 7d / 30d / 长期，下载次数分档
  • 可选 4 位提取码、一次性下载、撤销
  • 二维码分享、批量邮件发送收件人（≤5 人）
  • 多文件 client-zip 浏览器端流式打包

预览 · 在线直看

  • 图片画廊 + 灯箱 + EXIF 元数据（exifr）
  • PDF / 纯文本 / Office（docx / xlsx / pptx 浏览器端渲染）
  • 视频：自研播放器优先，原生 Video 兜底分流
  • 不支持格式智能探测并提示下载

收件 · 反向请求

  • /r/[code] 收件链接：收作业、收合同、收素材
  • 仅注册用户可创建；访客直接向链接提交文件
  • 访客上传计入创建者配额，访客侧仅 IP 限频
  • 可选 4 位访问码与有效期，过期即停收

工作台 · 我的文件

  • 登录用户 /my：分享与收件全量管理
  • 续期、改提取码、撤销、复制链接、扫码
  • 游客分享存于本地（localStorage），支持自撤销
  • 分享过期/次数耗尽状态一目了然

运营 · 管理后台

  • 分享 / 举报 / 用户 / 邮件队列 / 收件投递箱
  • 公告、版本化配额策略、下载配置
  • 豆包 Session 状态与扫码维护、诊断面板
  • 审计日志与统计总览、IP 来源分析
技术深潜 · 自研亮点

三个别人直接抄不到的模块。

这个项目最硬的部分不是 CRUD，而是媒体播放、配额结算与对象存储直传三条「自己长出来」的技术线。

SELF-DEVELOPED PLAYER

01 · 自研 SDP 媒体播放器

frontend/src/lib/sdp/ · 8 个核心模块

为了让分享页能够播放浏览器原生不支持的封装/音频组合（如 MKV 容器、AC-3 / E-AC-3 音轨），团队从零实现了 WebCodecs 之上的 SDP 播放引擎：JS 解复用 → 音频主时钟同步 → 视频渲染，并配套一整套真实回归脚本。

解复用与缓存

demuxer.ts 解析容器与分轨；packet-buffer.ts 管理包缓冲与背压；mkv-seek-index.ts 为 MKV 建立随机访问索引，拖动秒级定位。

音视频同步

以 audio-context-probe.ts 探测输出能力，audio-renderer.ts 用 AudioContext 主时钟驱动渲染循环（sdp-audio-master-clock 方案），避免音画漂移。

分流矩阵与回退

按容器与音轨 codec 决策：AC-3 / E-AC-3 走 sidecar 播放；MKV 原生 Video 兜底；其余走自研引擎。配套 codec-matrix / ac3 / mkv-native 三套 smoke 脚本常驻验证。

VERSIONED QUOTA POLICY

02 · 版本化配额策略与补偿结算

backend/app/services/quota_policy.py · quota_reconciliation.py

配额不是写死的开关，而是「可版本化的策略」：管理员先编辑草稿，看到影响预览，再预约发布时间；发布后支持历史回滚。消费侧用 Redis 滑动窗口记录上传，并做上传预留与后台补偿结算。

策略生命周期

草稿 → 影响预览（预演新旧策略对配额的影响）→ 预约发布 → 历史记录 → 回滚。策略版本与产品版本独立递增，迁移基线固定。

日月周期额度

额度统计周期支持日/月维度并适配北京时间；上传前预留额度，失败自动释放，避免并发抢占导致超发。

补偿结算

FastAPI 启动即拉起后台循环，每 60 秒将 Redis 中的未结算额度和预留记录对账入 PostgreSQL（quota settlements reconciliation），重启后不丢账。

DOUBAO TOS DIRECT-UPLOAD

03 · 豆包 TOS / ImageX 直传链路

backend/app/services/doubao_client.py · 956 行

对象存储是 ImageX 专有 API + 专有鉴权（非标准 S3），且上传权限依赖可失效的 Doubao Session——这部分没有现成轮子，全部自研并经受生产验证。

上传与签名

prepare → apply → commit 三段式直传 + AWS SigV4 内联签名；实测单 PUT 512 MB–1 GiB 稳定（2 GiB 全 503），据此定分片方案。

Session 保活

心跳后把 cookies 持久化到 session 文件（heartbeat + persist），失败自动回退下载备用 Session；管理后台可视化 Session 状态并支持扫码刷新。

隔离的媒体 Worker

独立 media-worker 容器处理媒体元数据与视频检测，只读根文件系统 + 丢弃全部 capability + 禁止提权，2 GiB / 2 CPU 限额，20 分钟优雅停机。

系统架构

浏览器直传，服务器只管"名分"。

一条红线贯穿整个架构：文件的字节流不经过 VPS。上传与下载都发生在浏览器与对象存储 / CDN 之间；FastAPI 只签发凭据、记账与审计。

单文件传输模型

浏览器 → 后端申请上传凭据 → 直传豆包 TOS → 提交 commit 生成分享 → 接收方凭短码获取 CDN 下载 URL，凭据有时效。

多文件 / 打包模型

多文件分别直传后归入同一个分享；下载时浏览器端 client-zip 流式打包，或按序 Range 请求分块写盘（File System Access），全程不占服务器内存。

后台任务模型

邮件出站、收件投递箱导入、Nginx 访问日志导入、GeoIP 更新、管理维护等均由 systemd timer 驱动；配额补偿结算为 FastAPI 内嵌异步循环。

安全与风控

传输工具的安全感，来自七层防御。

分享类产品天然吸引滥用，因此风控从第一天就设计进架构，而非事后打补丁。

凭据与口令

提取码 Argon2 哈希存储；会话 Cookie + CSRF 防护；密码重置走邮箱验证码；弱密码库拦截。

不可枚举设计

6 位 base62 短码（≈568 亿空间）；提取码错误指数退避 + 临时封禁；系统保留路由不与短码冲突。

内容安全

SHA256 黑名单（abuse.ch MalwareBazaar 每日 feed + 举报/人工入库）在上传前快速命中；举报进后台人工处理。

审计追踪

全量 audit_logs（actor / action / target / JSONB payload）；IP 行为日志保留 180 天后硬删；分享创建来源随生命周期保留。

身份与限流

游客以加密 Cookie + GeoIP 识别；上传额度按 IP / 用户双维度；访客收件仅 IP 频率限制；上传接口走 altcha 人机验证。

合规与可用性

用户协议 / 隐私政策 / DMCA 投诉全量提供；明确禁止违法、版权、CSAM 与恶意软件内容；豆包 TOS 第三方存储可见性告知。

加固项实践
容器media-worker 只读根文件系统 · cap_drop ALL · no-new-privileges · pids 上限
网络Postgres / Redis / Bark 仅监听 127.0.0.1；TLS 由 Nginx 终止
生产OpenAPI / Swagger 生产环境关闭；日志轮转限量保留
幂等分享事件幂等键防重放（share_event_idempotency_keys）

邮件信誉（自建 Postfix）

SPF + DKIM（2048-bit）+ DMARC 全链路 PASS；mail-tester 评分 8.8 / 10；主流 IPv4 黑名单零收录。支持收件投递箱导入（Maildir）与失败重试队列，后台可监控邮件状态。
