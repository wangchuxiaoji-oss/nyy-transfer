03 · ADMIN CONSOLE
运营管理后台

从“能上传”到“能运营”：
后台覆盖内容、用户、沟通与系统策略。

后台不是附带页面，而是生产系统的控制中心。管理员从总览进入带筛选的待办模块，完成调查、处置、配置与审计闭环。

运营与治理

总览 · 分享 · 举报 · 用户

总览：汇总待处理举报、异常访问、失败邮件、豆包失效及当天运营趋势。

分享：按状态、时间、文件数、容量和风险筛选；查看详情、预览内容、调查来源并封禁/解封。

举报与用户：举报可联动封禁；用户支持启禁用、软删除、邮箱验证、计划调整与密码重置。

沟通与发布

邮件 · 收件箱 · 更新发布

邮件队列：查看待发、成功与失败状态，定位失败原因并重新提交投递。

收件箱：提供邮件线程、附件、回复、转发、星标、归档、垃圾邮件与删除处理。

更新发布：公告支持草稿、编辑、发布和归档，用户只收到一次新提醒。

系统策略

配额 · 下载行为

版本化配额：分别配置游客和注册用户的文件大小、周期额度、有效期及活跃分享数。

策略支持草稿、影响预览、预约生效、不可变历史和回滚，避免直接修改生产规则。

下载配置：控制智能下载、File System Access、离页提醒及按文件类型启用增强行为。

运行维护

豆包 · 诊断 · 审计 · 归档

豆包 Session：主动验证可用性、展示到期与错误，并支持二维码刷新生产会话。

诊断与来源：检查服务状态，结合 IP、地理位置和关联记录调查异常来源。

审计与归档：记录管理员操作；终态分享先预检再归档，保留可追溯性。

后台形成完整处理链：总览发现问题 → 进入带筛选模块 → 查看内容与来源 → 执行处置 → 写入审计 → 刷新运营信号。

04 · PRODUCT VALUE
这个网站是做什么的？

让一次临时文件交付，
不再依赖聊天软件和本地播放器。

适用于设计稿、摄影成片、视频素材、作业、合同等需要临时交付或集中收集的文件。

选择文件文件、多个文件或文件夹
→
浏览器上传实时进度与失败重试
→
生成短链接有效期、提取码与次数
→
预览或下载电脑、手机、微信均可
01

聊天软件限制大小与格式

超大文件难发送，视频和文档可能被压缩，历史文件也容易失效。

02

接收方要先下载才能判断内容

视频、PDF、Office 和图片缺少统一预览入口，沟通成本高。

03

文件交付缺少权限和生命周期

普通网盘链接难精细控制有效期、提取码、下载次数和撤销。

04

收集资料时文件散落在聊天记录

收件链接让外部访客直接提交，文件归入创建者的工作台。

05

大文件经过应用服务器成本高

文件本体由浏览器直传对象存储，VPS 不承担大文件中转。

06

运营者看不见风险和运行状态

后台统一处理举报、用户、额度、邮件、对象存储会话与诊断。

核心价值：发送方“选完就能分享”，接收方“打开就能判断内容”，管理者“看得见并能控制整个生命周期”。

08 · VIDEO ENGINE
核心亮点（一）：视频在线播放

原生优先，自研补齐浏览器能力边界。

不是所有视频都强行走自研解码。系统先读取上传时生成的媒体元数据，再根据容器、视频轨、音频轨和浏览器能力选择最稳妥的播放路径。

媒体元数据容器、codec、时长、faststart
→
能力探测原生 Video / WebCodecs / AudioContext
→
播放分流Native / SDP / AC-3 Sidecar
→
统一控制层进度、音量、倍速、全屏、PIP

Range 文件读取

自研 RangeFileReader 把单对象或多分片文件映射成统一逻辑文件；支持局部读取、超时、重试、备用 URL 和大区间并行切分，播放器不必下载完整文件。

容器解析与轨道选择

使用 MediaBunny 作为底层 demux 能力，通过自定义 Source 接入 CDN Range；提取主视频轨、音频轨、关键帧和持续时间。MKV 可使用上传阶段生成的 Cues 索引辅助 Seek。

自研 SDP 播放引擎

PlayerEngine 协调 Demuxer、PacketBuffer、VideoRenderer、AudioRenderer 与 PlaybackClock；处理 Play、Pause、Seek、页面可见性和网络背压。

WebCodecs 解码

视频交给 VideoDecoder 并绘制到 Canvas；标准音频使用 AudioDecoder，AC-3 / E-AC-3 通过 MediaBunny AC-3 解码路径输出 AudioSample。

音频主时钟与同步

AudioContext 的实际播放时间作为主时钟，视频渲染器按时钟调度帧；Seek 时重建音视频基线并进入缓冲状态，减少长视频拖动后的音画漂移。

稳定性策略

缓存关键帧、限制前向缓冲、监控读取速度与停顿、取消过期 Seek 请求；原生能力可靠时不接管，出错时提供下载或备用路径。

自研边界

Range 读取、播放状态机、缓冲、时钟、Seek 和渲染调度为项目实现；MediaBunny 提供底层容器/包抽象，WebCodecs 与 AudioContext 提供浏览器解码和音频输出。

真实示例说明：本 PDF 中的 `.m4v` 示例为 H.264 / AAC，当前浏览器可原生播放；自研 SDP 主要用于 MKV、特殊音轨和原生支持不完整的场景。
